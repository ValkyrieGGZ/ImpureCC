# Impure.cc | BRM5

Clean, keyless Blackhawk Rescue Mission 5 script.

## Features

### Combat
- Silent Aim (FOV, distance, visibility check, team check, target part selection)
- FOV Circle
- Recoil Multiplier
- Spread Multiplier

### ESP
- Boxes (Normal / Corner)
- Chams (Highlight / Adornment / MeshChams)
- Names, Distance, Weapon, Health
- Off-screen Arrows
- Team / Squad filter
- Max distance

### Misc
- Omnisprint

### UI
- LinoriaLib
- Config system
- Theme support
